# ReBook - Campus Book Exchange

A simple website where college students can buy, sell or donate used books, notes and lab items.
Made for a college hackathon.

## Problem
First year students spend a lot of money on books and lab items that they use for only 1-2 semesters.
Seniors have these items lying unused, but there is no proper way to connect them. Right now it
happens through WhatsApp groups where messages get lost.

## Features
- Add an item (book, notes, lab item) with price and contact details
- Search items by name
- Filter by branch
- Donate mode: set price to 0 and the item shows as FREE
- Stats: items listed, free items, and total money saved by students
- Data is stored in the browser using localStorage

## Tech used
- HTML
- CSS
- JavaScript

## How to run
1. Download or clone this repository
2. Open `index.html` in any browser

No installation needed.
